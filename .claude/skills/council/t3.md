# council: T3 Code path

Extends [SKILL.md](SKILL.md); its rules still apply. This file says which T3
tools to use.

## Seats (multi-vendor)

One strong model from each of three different providers: the latest flagship
from each, for example Claude Opus, GPT Sol, and Gemini Pro. Use
`orchestrator_capabilities` to resolve the models, then `delegate_task` to
start one delegate per model in parallel. Gemini comes from the `antigravity`
provider. In Claude Code, T3 tools are deferred: load them first with
ToolSearch
`select:mcp__t3-code__orchestrator_capabilities,mcp__t3-code__delegate_task`.

If a vendor's flagship is not on the account (e.g. no Gemini Pro), seat that
vendor's strongest available model and use its real name in the results.
Providers are model vendors (Anthropic, OpenAI, Google), not T3 provider
instances; a second model from a vendor already seated does not count.
