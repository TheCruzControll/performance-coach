# leaving-pr-comments: T3 Code path

Extends [SKILL.md](SKILL.md); its rules still apply. This file says which tools
to use in T3 Code.

## GitHub access

Use whatever the session has, such as the `gh` CLI (if logged in), a GitHub
MCP server, or built-in GitHub tools (search ToolSearch for `github`). If
nothing reaches GitHub, stop and say so.

## Model name

Use the model name the T3 Code session or provider exposes for the thread
writing the comment. If none is exposed, use the harness name (T3 Code).
