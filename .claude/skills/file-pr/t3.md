# file-pr: T3 Code path

Extends [SKILL.md](SKILL.md). Its rules still apply; this file says which tools
to use in T3 Code.

## GitHub access

As in SKILL.md (whatever the session has). T3 Code adds no PR filing tool of
its own.

## Attribution

T3 Code runs Claude Code or Codex underneath. Name T3 Code as the harness and
use the model name the session reports, for example
`Created with <model> in T3 Code.` Include models of `delegate_task` children
that wrote part of the change.

## Babysitting

If the user also asked to babysit the PR, continue with the `babysit-pr` skill;
its T3 path watches the PR with `watch_pull_request`.
